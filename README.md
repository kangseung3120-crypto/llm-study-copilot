# LLM Study Copilot

AI-powered personalized learning assistant built with LLM and RAG.

## Project Goal

LLM Study Copilot is an AI learning assistant that helps users study technical topics using their own learning materials.

The service will support:

* Document-based Q&A using RAG
* Source-aware answers
* Personalized explanations
* Quiz generation
* Learning progress analysis
* AI Agent-based learning assistance

## Tech Stack

* Python
* FastAPI
* Ollama
* Hugging Face
* Vector Database
* Docker
